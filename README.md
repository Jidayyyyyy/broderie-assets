# broderie-assets

Fichiers chargés par le site Wix de **Mes Premiers Rêves** pour la personnalisation des produits (broderie et impression DTF).

| Fichier | Rôle |
|---|---|
| `embroidery-preview.js` | Custom Element `<embroidery-preview>` : aperçu client (broderie point par point, logo DTF) |
| `zone-editor.js` | Custom Element `<zone-editor>` : éditeur des vues et zones de personnalisation (administration) |
| `fonts/*.json` | Points de broderie des polices proposées |

Servis par jsDelivr, par version :

```
https://cdn.jsdelivr.net/gh/Jidayyyyyy/broderie-assets@v1.0.0/embroidery-preview.js
https://cdn.jsdelivr.net/gh/Jidayyyyyy/broderie-assets@v1.0.0/zone-editor.js
https://cdn.jsdelivr.net/gh/Jidayyyyyy/broderie-assets@v1.0.0/fonts/
```

Polices fournies pour la démonstration ; leur usage commercial dépend de la licence de chaque police.
